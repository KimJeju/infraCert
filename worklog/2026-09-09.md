### 3. 룰팩 + 네이티브 룰 (B안)
- `rulepack/loader.py` + `rulepacks/kisa-2026/manifest.yaml`: 번들 3(aix-unix / oracle-db+.sql 동반 / web-was), SHA-256 무결성, `side_effects: read` 강제(조치형은 **로드 거부 후 목록 표시**), provides 대조, 프로파일 5. 스크립트는 `cowork/korea_bank_infra_scripts` 에서 복사.
- `rules/unix.py` 네이티브 14종(U-01~06, 09~13, 15, 45, 64) + `orchestrator/native_runner.py`. 룰은 원문 판정(GOOD/VULN/MANUAL/NA)만 내고 `decide()` 가 Status 확정. 플랫폼 불일치→SKIPPED, 예외→ERROR.

### 4. 파서 — 실제 산출물이 CSV 가 아니었다
- 현재 스크립트 3종은 **텍스트 리포트** 를 낸다: aix `[양호]  U-01(상)  이름`, oracle/web `D-02 | 양호 | 근거`, `WEB-01(T) | ...`.
- `parsing/report_txt.py`(두 형식) + `parsing/dispatch.py`(확장자·내용으로 파서 선택).
- **버그 발견·수정**: 근거 `>>` 가 헤더 **앞**에 오는 구조(detail→result)라 한 칸 밀려 귀속됐음 → "직전 근거를 다음 헤더에 귀속" 으로 통일. 실제 aix 산출물 67건으로 검증.
