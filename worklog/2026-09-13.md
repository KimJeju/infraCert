## 세션 11 — [CC] UI/UX 정보 구조 재설계 (단일 Nav · 자산 탐색기 · 진단 위저드 · 결과 3-pane · Ctrl+K)

형이 준 UI/UX 재설계 명세(문제 7가지 → 구조 18항목, P0/P1 만, 애니메이션·아이콘 P2 제외). 순서대로 **wireframe + component hierarchy 먼저**(`docs/UI_재설계.md`), 그다음 PySide6 셸 교체. 엔진·룰팩·결과 DB·provenance·세션 구조는 손대지 않았다(핸들러 전부 그대로 이식).

### 구조
- **NavRail**(`ui/nav.py`, 132px): 업무(개요·자산·진단·결과·보고서) / 도구(룰팩·터미널·SFTP·멀티실행·수동확인) / 설정. 워크스페이스는 `QStackedWidget` 11페이지. 상단 탭 + 사이드바 카드 + 메뉴 세 갈래이던 이동 경로를 하나로.
- 상단 메뉴는 파일·보기·도구·도움말(시스템 기능만). 메뉴 우측엔 **크리덴셜 상태만**. 상시 노출 "완전삭제 후 종료" 버튼 제거 → **파일 → 세션 종료 및 완전삭제…**(`ui/exit_dialog.py`: 작업공간/임시파일/크리덴셜(항상) 체크박스, 미반출 경고, 버튼 문구가 선택에 따라 "완전 삭제 후 종료"/"종료"). 창 X 는 예전처럼 설정 기본값을 따르고, 미반출 결과 + 완전삭제 기본이면 같은 다이얼로그로 확인.
- 상태 바: 룰팩 검증 여부 · 자산 수 · 세션 상태(진단 중/미반출/진단 id/없음) · 엔진.
- **Ctrl+K 명령 팔레트**(`ui/palette.py`): 이동·진단·분석·도구·자산·시스템 27개 명령 + 검색 제공자(자산 라벨/주소/고객사, 룰 id/이름, 현재 진단의 취약점 → 결과 화면 해당 항목).

### 화면
- **개요**: 빈 상태(자산 → 진단 안내 + [첫 진단 시작]) / KPI 4개(자산·마지막 진단·취약점·조치율) → 판정 카드 → 위험 현황 + **조치 필요(오늘 할 일)** → 최근 진단(호스트·룰·VULN·완료) → 조치 현황·호스트별 분포. 조치 필요 더블클릭 → 결과 화면에서 그 항목 선택.
- **자산**(`ui/pages/assets.py`): Asset Explorer(왼쪽) + **호스트 상세**(작업영역; 사이드바 카드 `host_card.py` 는 삭제). 트리 별칭 `win.tree/model/filter` 유지(테스트·`_selected_hosts`).
- **진단**(`ui/pages/scan.py` 재작성): ① 대상(선택 자산 표 + "자산에서 추가…") ② 프로파일(**Auto Detect** = `discovery.recommend_profiles` / 플랫폼 기본, 프로파일 카드 종류·항목 수·자동/수동) ③ 실행 설정(동시 실행·타임아웃·사전검증·**자동 재시도 1회**·완료 후 결과 열기) + 요약(룰팩 SHA ✓·대상·룰·Read-only). 실행 중 **진행 뷰**(전체 %·호스트 표·현재 작업 = 호스트 / 룰) → 완료 후 [결과 보기][재진단][새 진단]. 호스트별 프로파일이 다르면 `ScanResult.profile="auto"`.
- **결과**(`ui/pages/result.py` 재작성): 목록 / Finding Detail / Evidence 3-pane. 상태 컬럼 = 아이콘 + 텍스트(`theme.STATUS_ICON`, `status_label`). 상세: 판정·Expected/Actual 또는 판정식+추출값·위험도·전회/변화·예외·룰 변경·점검 목적·판단 기준·조치 방법. 아래 [파일 열기][터미널][해당 룰][**재진단**(이 호스트만 같은 프로파일)]. 기동 시 마지막 진단을 결과·수동확인에도 올린다(예전엔 대시보드만).
- **보고서**(`ui/pages/reports.py`): 진단 선택 + 품질 게이트 + XLSX/HTML + 세션 zip.
- **터미널/SFTP**(`ui/pages/sessions.py`): 페이지 안 세션 탭, Nav 배지 "(n)", "브로드캐스트" → **"선택 탭 동시 입력"**.
- 테마: `nav-btn/nav-group/palette/kpi-*` QSS, 다크 유지. 1365×860 기준·최소 1280×720 오프스크린 렌더 확인(개요/자산/진단/진행/결과/보고서/팔레트/터미널).
