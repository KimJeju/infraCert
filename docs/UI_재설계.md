# InfraGuard UI 재설계 (정보 구조) — 2026-09-13

목표: 기능·백엔드·데이터 모델·룰팩·provenance·세션 구조는 그대로 두고 **정보 구조(배치·우선순위·발견성·작업 흐름)** 만 바꾼다.
기준 해상도 1365×860, 최소 1280×720 에서 핵심 기능이 잘리지 않는다. P2(애니메이션·아이콘 세부)는 하지 않는다.

## 1. 문제 → 결정

| # | 문제 | 결정 |
|---|---|---|
| 1 | 상단 메뉴(파일/자산/진단/도구/도움말)와 업무 탭(대시보드/진단/결과…)이 둘 다 네비게이션 | 메뉴는 시스템 메뉴만(파일·보기·도구·도움말). 업무 이동은 **왼쪽 Nav Rail** 하나로 |
| 2 | 자산 사이드바가 탐색·상세·액션·관리를 다 함(폭 30%) | 사이드바 없음. **ASSETS 화면** 안에 Asset Explorer(왼쪽, 300px) + Host Detail(오른쪽 작업영역) |
| 3 | 대시보드가 빈 차트로 가득 | 결과 없으면 **Empty State + [첫 진단 시작]** 만. 있으면 KPI 4개 · 위험 현황 · 조치 필요 · 최근 진단 |
| 4 | 진단 화면 대상 영역이 텅 비고 설정이 구석 | **3-step**(① 대상 표 ② 프로파일 카드 ③ 실행 설정+요약) → 시작하면 **진행 화면으로 전환**(현재 작업 표시) |
| 5 | 결과 표가 넓고 상세는 아래 작은 박스 | **Findings 3-pane**: 목록 · Finding Detail(판정/Expected·Actual/위험도/조치) · Evidence(명령·출력·판정식) + [터미널][파일][룰][재진단] |
| 6 | 완전삭제 빨간 버튼 상시 노출 | 제거. 파일 → **세션 종료 및 완전삭제**(체크박스 확인 다이얼로그) |
| 7 | "브로드캐스트" 이름 | 터미널 화면 안 "**선택 탭 동시 입력**" 으로 이동·개명 |
| + | 발견성 | **Ctrl+K Command Palette**(명령 + 자산 검색 + 룰 검색) |
| + | 색만으로 상태 구분 | 상태 = 아이콘 + 텍스트 + 색 (`✓ 양호` `✗ 취약` `? 수동확인` `– 해당없음` `! 오류`) |

## 3. Component hierarchy

```
MainWindow (frameless)
├─ TitleBar
├─ QMenuBar: 파일(세션 내보내기/가져오기 · 세션 종료 및 완전삭제 · 종료) 보기(화면 이동 · Ctrl+K) 도구(Discovery · 멀티실행 · 지금 완전삭제…) 도움말
│  └─ corner: ● 크리덴셜 상태 (버튼 없음)
├─ QSplitter
│  ├─ NavRail (ui/nav.py)  — 업무 / 도구 / 설정 그룹, 현재 표시, 배지(터미널 수)
│  └─ QStackedWidget
│     ├─ overview  DashboardPage (ui/pages/dashboard.py, empty state + KPI + 조치 필요)
│     ├─ assets    AssetsPage (ui/pages/assets.py) = Explorer(filter·groups·tree·add/import) | HostDetail
│     ├─ scan      ScanPage (ui/pages/scan.py) = QStackedWidget[setup(3-step) | progress]
│     ├─ findings  ResultPage (ui/pages/result.py) = filters | QSplitter[list | detail | evidence]
│     ├─ reports   ReportsPage (ui/pages/reports.py)
│     ├─ manual    ManualBenchPage (기존; 결과 화면 "수동확인 워크벤치" 버튼·팔레트로 진입)
│     ├─ rulepack  RulePackPage (기존)
│     ├─ terminal  SessionTabs(terminal)  (ui/pages/sessions.py)
│     ├─ sftp      SessionTabs(sftp)
│     ├─ multiexec MultiExecPage (기존)
│     └─ settings  SettingsPage (기존)
├─ QStatusBar: 룰팩 검증 · 자산 수 · 세션 상태 · 엔진
└─ CommandPalette (ui/palette.py, Ctrl+K)
```

## 4. 상태 표기 (색 + 아이콘 + 텍스트)

| 상태 | 표기 | 색 |
|---|---|---|
| GOOD | ✓ 양호 | green |
| VULN | ✗ 취약 | red |
| MANUAL | ? 수동확인 | amber |
| NA | – 해당없음 | gray |
| ERROR | ! 오류 | purple |

## 5. 범위

P0(이번): Nav Rail 단일 네비게이션 · Assets 화면(Explorer+Detail) · Overview empty state/KPI · Scan 3-step+진행 · Findings 3-pane · 위험 버튼 제거(세션 종료 다이얼로그) · 브로드캐스트 개명/이동.
P1(이번): Ctrl+K 팔레트(명령·자산·룰 검색) · 상태바 세션 상태 · Reports 화면 · 호스트 컨텍스트 액션 통일.
P2(안 함): 애니메이션·아이콘 세부.
